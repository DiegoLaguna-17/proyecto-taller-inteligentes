# 3. Selección de Azure como Entorno de Despliegue Cloud

* **Estado:** Aceptado
* **Fecha de decisión:** 2026-08-17
* **Autores:** Equipo GlucoTracker

## Contexto y Problema
El sistema debe estar preparado para un entorno Cloud escalable según los requerimientos institucionales y de la arquitectura definida.

## Alternativas Consideradas
1. **AWS (Amazon Web Services):** Excelente ecosistema, pero con curvas de aprendizaje diversas para el equipo en esta etapa.
2. **Microsoft Azure:** Proveedor cloud seleccionado por disponibilidad institucional/preferencia del equipo y buenas herramientas para contenedores y APIs.

## Decisión Tomada
Se decide utilizar **Azure** como plataforma oficial para el despliegue del backend y servicios asociados.

## Consecuencias
* **Positivas:** Alineación con las directrices tecnológicas del equipo y el proyecto, y facilidad de integración con servicios administrados.
* **Negativas / Riesgos asumidos:** Dependencia de la capa gratuita o créditos disponibles en la plataforma durante el desarollo.
